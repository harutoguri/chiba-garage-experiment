チバガレージ ライブサイト総評

対象: https://chibagarage.com ／ 2026-06-09 実機（iPhone相当）レンダリング＋HTTP実測ベース ／ 全7ページ＋車両詳細導線を確認
総括：前回指摘していたSEOの土台（ドメイン統一・sitemap・ルート別メタ・JSON-LD）はほぼ全部直っていて大きく前進。 文章コンテンツ・法令ページの作り込みも良い。
一方で「売上に直結するのに、もったいない」未対応が3つ残っている： ①車両ごとのページ（URL）が無い、②SNSシェア画像が壊れている、③在庫を探す手段（検索・絞り込み）が無い。 さらに会社概要ページのアイコンが💩絵文字など、信頼を落とす要素がある。ここを直すと成績は確実に上がる。

これはダメ今すぐ直すべき（成績を落としている）

1. 車両ごとの独立ページ（URL）が存在しない ← 最大の機会損失

在庫の「車両詳細」を押しても URLは / のままで、その場で開くだけ。1台ごとのページが無い。実際、押した車両は 「詳細情報はまだ登録されていません」と表示された。

何がもったいないか：

  • Googleに1台ずつ載らない。「CX5 中古 大崎市」「クラウン 中古 古川」等で個別車両が検索ヒットしない＝一番おいしい検索流入を丸ごと捨てている。
  • URLを共有できない。LINEで「この車どう？」と1台のリンクを送れない。商談・拡散の致命傷。
  • サイトマップにも車両ページが1つも無い（静的7ページのみ）。

対応：車両ごとに /vehicle/<id> のような独立URLを作り、サーバー側で各車の title / description / OGP / JSON-LD(Car/Vehicle, price, mileage, year) を埋め込む。これが中古車サイトの心臓部。

2. SNSシェア用の画像（OGP）が壊れている

全ページが og:image = https://chibagarage.com/og-image.jpg を指しているが、その画像を実際に取得すると画像ではなくHTMLが返ってくる（ファイルが存在しない）。

影響：LINE・Instagram・X等でURLを貼ったとき、サムネイル画像が出ない／崩れる。SNS集客が主体の店にとって、クリック率を大きく下げる「もったいない」バグ。

対応：実在する og-image.jpg（1200×630推奨）を配置。理想は車両ページごとにその車の写真をOGPに。

3. 会社概要ページのブランドアイコンが💩絵文字／ニュースが内輪ネタ

会社概要(/about)の「チバガレージ CHIBA GARAGE」のロゴ枠がうんち（💩）の絵文字になっている。さらに最新情報に「高すぎて毎日おにぎり生活です。ご飯を恵んでください。」等の内輪ネタ投稿。

影響：数十万〜百万円の買い物をする客が「会社概要」で信頼を確認する場所。ここで一気に不信感を与える。SNSのノリと、購入判断ページのトーンは分けるべき。

対応：ロゴ画像を正式なものに差し替え。ニュースは「買取実績・入庫情報・キャンペーン」など信頼につながる内容に。

もったいない直すと成績が上がる（高効果）

4. 在庫を「探す」手段が無い（検索・絞り込み・並べ替えゼロ）

全ページに検索ボックスも絞り込みも無し。在庫は縦スクロールで延々流れるだけで、価格・年式・走行距離・車種・ボディタイプで絞れない。さらに「成約済」の車が在庫一覧に大量に混在している。

影響：買う気の客ほど「予算◯万円のミニバン」を探したい。探せない＝離脱。在庫が増えるほど悪化する。

対応：一覧に絞り込み（価格帯・車種・年式・走行）と並べ替えを追加。成約済はデフォルト非表示か末尾へ。「映える」動画体験は残しつつ、探せる導線を主役に。

5. ページの「タイトル(meta)」と「中身」がズレている

SEOタイトルと実際の中身、メニュー名が三者バラバラなページがある：

URLSEOタイトル(meta)実際の中身 / メニュー名
/consignment「車の委託販売…個人売買より安心」中身は「個人売買掲示板」。本文で“委託車両ではありません”と明記／メニュー名は「個人売買」
/trade「中古車の個人売買サポート」中身は「買取／販売」の入口（選択ページ）／メニュー名は「買取/販売」

影響：タイトルで来た人が中身の違いで離脱（直帰率↑）。Googleもタイトルと内容の不一致を嫌う。URL名・メニュー名・タイトル・中身を一本化すべき。

6. トップ（在庫一覧）が重い・通信量がもったいない

  • トップ初回で約8MB転送。画像215枚を遅延読込なしで一括ロード（loading="lazy"無し、srcset無し）。
  • サムネがJPEGのまま・1枚あたり約235KB（WebP/AVIF化で30〜50%削減可）。サムネにしては大きすぎる。
  • 動画要素が17個同時にDOM上に存在。

影響：モバイル回線で表示が重く、ギガも食う。直帰につながる。遅延読込＋WebP化＋一覧の仮想化（画面内だけ描画）＋成約済の出し分けで大幅に軽くなる。

7. HTML本体が圧縮されていない

JS/CSSは gzip＋1年キャッシュで良好。だがHTMLドキュメント自体は約88KBを無圧縮（br/gzipを要求しても content-encoding 無し）。しかも no-store で毎回フル取得。

対応：HTMLもgzip/brで配信すれば 約88KB→15〜20KB。サーバー設定1つで効く、コスパの良い改善。

細かいが効く仕上げ

  • 画像のalt属性が全滅（トップ215枚すべてalt無し、aboutも4/5無し）→ 画像検索流入・アクセシビリティの損。車種名を入れる。
  • サムネのキャッシュが1日（max-age=86400）→ UUID固定で実質不変なので1年に。
  • 存在しないURLでもHTTP 200を返す（ソフト404）。表示は404だがステータスは200 → 正しく404を返す。
  • 連絡FABボタン（電話/メール/LINE/IG）が本文に被る位置。カードやボタンと重なって押しづらい場面がある。
  • トップのキャッチが弱い：「次世代型中古車個人売買プラットフォーム誕生」は抽象的。ロゴ文字も明るい空背景でコントラスト不足で読みにくい。「大崎市の中古車買取・販売／LINEで写真査定」など具体便益を。
  • 診断用APIが本番に露出（/api/debug-log, /api/net-capture）→ 不要なら塞ぐ。
  • /submit(出品)に固有メタ無し（canonicalが /）。フォームなら noindex 推奨。

改善済み・強み前回から良くなった点

  • ドメインを chibagarage.com に統一（canonical/OG/robots/sitemap）← 前回の致命傷を解消。
  • sitemap.xml が実在し、robots.txt も正しいドメインを指す。
  • ルートごとにサーバー側でメタ（title/description/canonical/JSON-LD）を出力。SNSスクレイパにも見える。
  • タイトルがキーワード入りで具体的（例:「車買取 大崎市・古川ならチバガレージ｜LINE写真査定・車検切れ相談OK」）。
  • 買取/販売/会社概要/特商法ページの文章が充実。古物商許可番号・特商法表記など法令面はしっかり。
  • TTFBが速い（軽いページで応答 60〜210ms）。静的アセットはgzip＋1年キャッシュ。
  • LINE/電話/メール/Instagram の連絡導線あり。

対応おすすめ順

  1. 車両ごとの独立ページ(URL)＋車両別メタ/OGP/JSON-LDを作る（SEO・共有の心臓部）
  2. OGP画像 og-image.jpg を実在させる（SNSシェアのサムネ復活）
  3. 会社概要のロゴ(💩)差し替え＋ニュースのトーン見直し（信頼回復・すぐ直せる）
  4. 在庫の検索/絞り込み/並べ替え＋成約済の出し分け（買う側の導線）
  5. メタとページ内容の不一致を一本化（/consignment・/trade）
  6. トップの軽量化（画像 遅延読込＋WebP化＋仮想化）＋HTMLのgzip化
  7. alt付与・404ステータス・サムネ長期キャッシュ・FAB位置・診断API遮断
